# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это просто файл-ссылка на коммит. Создаётся мгновенно. В SVN ветка — это копия всего проекта на сервере, каждый коммит идёт через сеть. Поэтому в Git веток можно сколько хочешь, а в SVN каждая ветка — нагрузка на сервер.

## 2. Можно ли в SVN сделать коммит без интернета?

Нет. SVN всегда шлёт коммиты на сервер напрямую. Без сети можно только редактировать файлы, но сохранить изменения не получится. В Git коммиты живут локально, пушить можно потом когда появится интернет.

## 3. Когда SVN ещё может быть лучше Git?

- В госсекторе и банках, где всё уже давно на SVN и миграция слишком дорогая
- Когда нужны права доступа на конкретные папки (Git умеет только на весь репозиторий)
- Когда проект держит кучу больших бинарников (Git тащит их целиком, SVN — нет)
